# ToolFleet web

Angular 22 frontend. Run the API first (see the root README), then:

```bash
npm install
npm start          # http://localhost:4200, /api is proxied to http://localhost:5080
npm test           # Vitest, watch mode
npm run build      # output in dist/web/browser
```

Needs Node 22.22.3+ or 24.15+.
